# Escalation

Use this when the rep says "tell my manager" / "πες το στον προϊστάμενο".

1. Make sure you know the account and the reason in the rep's words. Resolve the shop with resolve_account if needed.
2. Read back one line: "Θα πω στην Ελένη ότι ... για το ...". After a clear yes, call escalate_to_manager with the account id and the reason.
3. Say that the manager got a task, using the name from the result.
